# SIRIUS 3.0 VENUS - Página web

## Requisitos
- Python 3.10 o superior
- Visual Studio Code
- Flask

## Instalación

Abre CMD dentro de esta carpeta:

```cmd
py -m pip install -r requirements.txt
```

## Ejecutar

```cmd
py app.py
```

Después abre:

http://127.0.0.1:5000

El archivo `sirius.exe` se encuentra en:

`static/downloads/sirius.exe`

La ruta `/descargar` entrega el archivo como descarga.
